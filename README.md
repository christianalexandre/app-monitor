# App Monitor

Monitor de rede e ferramentas de debug para apps **iOS**, **Android** e **Kotlin Multiplatform**.
As requisições são enviadas em tempo real para um app desktop em **Compose Multiplatform** (macOS, Linux, Windows),
que também expõe um **servidor MCP** para agentes de IA consultarem o tráfego, runs, issues e benchmarks.
