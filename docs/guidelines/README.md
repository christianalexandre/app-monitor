# Guidelines

Prescriptive rules: **how to write** code, docs, commits and PRs. If a chapter
only describes how the system is, it belongs in `sdd/`.

Rules:

- A rule changes through an ADR, in the same PR that updates the chapter.
- New chapter: copy `_template.md` to `NN_topic.md` and add it below.
